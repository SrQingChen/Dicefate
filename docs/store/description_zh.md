# 骰掷命术 Dicefate

> **万物皆骰，命数自搏。**

你挥出的每一刀、僵尸扑来的每一击、Boss 砸下的每一锤——在《骰掷命术》的世界里，**每一次命中都是一场骰局**。攻守双方同刻掷出各自的骰池，点数对拼、胜负立判，命运在 0.1 秒的落定演出中翻牌揭晓。

这不是数值对撞的战斗，而是**读局、押注、构筑骰池的赌命艺术**。

## ✨ 为什么值得一试

- **🎲 拼点战斗** —— 所有玩家伤害走完整骰局管线：掷骰 → 拼点 → 战果。大胜全额命中，落败被格挡反制，Miss 灰头土脸
- **⚔️ 命势压制链** —— 打空对手命势，令其「命气散竭」全骰碎裂掷 0，再接命定真伤、命损易伤，环环相扣的进攻连段
- **📈 骰势兑现** —— 连击攒满骰势，按 `V` 一瞬引爆：我方全骰最大点 vs 敌方全骰归零，6 秒天命窗口
- **🧩 骰池构筑** —— 从 1 个 d6 骰位起步扩至 6 位；顺子 / 豹子 / 天命升格牌型；4 种元素反应、10 种协同、8 族技能骰自由搭配
- **🧊 真·多面体骰** —— 83 种骰全部是按精确数学坐标生成的 3D 多面体（d4–d24），编号面、材质配色，物品栏里就是一颗颗真骰子
- **🏰 专属内容** —— 4 个机制 Boss（双面赌徒 / 熔面骰王 / 霜寂女王 / 零面者）、6 座命途结构（命盘祭坛 / 倾颓赌坊 / 无面赌场…）、33 条进度、骰商村民与盲盒经济

## 🎮 30 秒上手

| 按键 | 功能 |
|---|---|
| `B` | 命盘：装骰 / 卸骰、切换姿态、保存 3 套预设 |
| `V` | 兑现：骰势将满 / 已满时引爆爆发窗口 |
| `G` | 骰灵开关：自动修正最低骰 +1 |

**开局循环**：刻骰台造骰 → `B` 装上 → 打怪拼点攒势 → `V` 兑现爆发 → 骰运台洗命纹、扩容符开骰位、追猎更稀有的骰。

## 🔗 兼容与说明

- 需要 **NeoForge 26.1.2+**（Minecraft 26.1.2），Java 25
- 可选联动：Curios（专属「命具」槽位）、Jade（命势面板，0.4 接入）、JECharacters（拼音搜索）——不在装时自动降级，功能不缺失
- ⚠️ 创造 / 旁观模式不参与拼点（设计行为），请用**生存模式**体验完整机制

当前 **0.3.2 beta**：核心拼点管线已实机生存验证，83 骰 / 4 Boss / 6 结构 / 33 进度全量可玩。遇 bug 或有好想法，欢迎到 GitHub Issues 反馈 —— 愿命途眷顾你的骰运。
